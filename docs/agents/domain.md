# Domain docs

Single context. The glossary is `GLOSSARY.md` at the repository root; decisions live in
`docs/adr/`.

- Read the glossary before naming a type, file, command, or UI label. If a term is missing,
  add it there first.
- Read the ADRs before changing simulation timing, renderer architecture, or deployment.
- A decision earns an ADR only when it is hard to reverse, surprising without context, and the
  result of a real trade-off. Everything else belongs in code comments or the PR body.
