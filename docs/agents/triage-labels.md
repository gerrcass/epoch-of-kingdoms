# Triage labels

The five canonical roles map 1:1 to these label strings:

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Will not fix | `wontfix` |

Specs and tickets created by the engineering skills start at `ready-for-agent`.
